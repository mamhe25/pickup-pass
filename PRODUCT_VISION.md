## ABOUT PICKUPPASS

PickupPass is a secure digital school dismissal management platform that streamlines and safeguards the student pickup process.

Its mission is to replace paper-based dismissal workflows with a secure, intelligent, and user-friendly digital experience.

PickupPass helps schools:

• Verify authorized pickups using secure QR codes
• Manage pickup requests
• Notify parents in real time
• Coordinate teachers during dismissal
• Track dismissal history
• Send school-wide announcements
• Monitor dismissal analytics
• Improve school safety
• Reduce congestion during dismissal

## IMPLEMENTATION STRATEGY

Do not redesign everything in one commit.

Work in structured phases.

For every phase:

1. Analyze the existing implementation.
2. Identify UX and UI weaknesses.
3. Explain why changes are needed.
4. Propose the redesigned solution.
5. Implement incrementally.
6. Verify that all existing functionality still works.

Maintain a buildable project after every phase.

## NON-NEGOTIABLE CONSTRAINTS

DO NOT:

• Break existing backend APIs
• Change authentication logic
• Modify authorization rules
• Remove existing features
• Break business workflows
• Reduce performance
• Introduce unnecessary complexity

The redesign must preserve every working feature while significantly improving the visual design, usability, and overall user experience.
